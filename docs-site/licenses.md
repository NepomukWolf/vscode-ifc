## IFC Format

Industry Foundation Classes (IFC) is a standard maintained by [buildingSMART International](https://www.buildingsmart.org/). The IFC specification is licensed under the [Creative Commons Attribution-NoDerivatives 4.0 International License (CC BY-ND 4.0)](https://creativecommons.org/licenses/by-nd/4.0/).

IFC Language Tools reads and interprets IFC STEP files according to the published schema. It does not redistribute or modify the specification itself.
